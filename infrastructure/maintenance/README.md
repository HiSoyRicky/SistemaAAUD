# Página estática de mantenimiento

Estos archivos son una propuesta local, no una configuración activa. El documento y el logo son independientes de React y del directorio de publicación. Copiar `index.html` y `logo-aaud.png` a un directorio estable de solo lectura para Apache, fuera del checkout y de los directorios de releases. El ejemplo usa `/var/www/aaud-maintenance/` y un indicador separado `/var/lib/aaud-deploy/maintenance.flag`; son rutas ilustrativas, no verificadas en producción.

El usuario describió el `DocumentRoot` actual como `/var/www/aaud-system/apps/backend/public`, con una reescritura SPA de rutas que no son archivos ni directorios y proxy para `/api/` y `/socket.io/`. No se ha podido inspeccionar el VirtualHost efectivo mediante SSH. Integrar el fragmento en ese VirtualHost solo después de verificar configuración, orden y precedencia de las reglas, módulos, permisos y configuración de proxy, y de probar `apache2ctl configtest` en una instalación aislada.

El indicador requiere un propietario/grupo y permisos que permitan al proceso de despliegue crearlo y retirarlo sin dar a Apache permisos de escritura. No exponer ese indicador por HTTP. Cuando existe, el ejemplo devuelve 503 y `Retry-After` solo a solicitudes GET o HEAD que aceptan HTML, sin interceptar `/api`, `/socket.io`, `/uploads`, `/fotos_personal`, otros recursos ni métodos de escritura; la política y errores del servidor siguen aplicándose a esas rutas. El documento de error y el logo permanecen accesibles sin recursión. Cuando no existe el indicador se mantiene la reescritura SPA original, salvo que los archivos ausentes de `/assets/` responden 404 y no `index.html`. El fragmento no modifica la respuesta de autenticación o autorización.

La regla de archivos ausentes depende del `DocumentRoot` efectivo y de que `/assets/` no tenga un `Alias` o proxy separado; confirmar estos supuestos antes de usarla. La integración real puede requerir modificar la regla SPA existente para evitar que vuelva a interceptar las respuestas 404. No activar en producción hasta probar las rutas normales y de error con la configuración completa. El botón recarga la URL original; sin JavaScript puede usarse el botón de recarga del navegador.

La regla SPA existente devuelve `index.html` para rutas desconocidas; Apache no puede distinguir una ruta válida de React de una ruta SPA inexistente con esa información, por lo que no se garantiza un 404 HTTP real para estas últimas. Los archivos ausentes bajo `/assets/` sí deben responder 404. La regla basada en Accept es una aproximación para navegación HTML, no detecta todas las formas de navegar; clientes sin ese encabezado conservan la respuesta normal.
